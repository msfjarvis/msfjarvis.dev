# Personal projects

I made a [big release](https://github.com/msfjarvis/compose-lobsters/releases/tag/v1.71.0) of Claw with some important fixes for the comments UX, and workarounds for dealing with Lobsters now being fronted by Anubis. It also includes a brand-new feature: a daily random saved post as a notification. I've found this to be quite nice since it gives me something interesting to read every morning as I'm waking up, and I can always drop it into my browser and have it read aloud podcast style. I have collected over 1,800 saved posts over the years and definitely haven't read a majority of them, so it also helps me get through that backlog in a drip-fed manner. I opted to not add a "sent posts" log but the data layer does capture this information, so the option is always there. Let me know if you think that'd be useful to have!

# Meta

This site got a major build speed improvement this week as I fixed an inefficiency in how I render Mastodon posts. Previously each Mastodon post would get fetched at build time, coming in at around 6 seconds per post and with the 3 embeds I have so far, making the weeknotes category take 19 seconds to render uncached. I've [now changed](https://github.com/msfjarvis/msfjarvis.dev/commit/1e9f82551d38ce1cf366a51cea1637976dca00df) this to use a static data store instead which is updated manually by a script that scans the site contents for Mastodon URLs and snapshots them. This adds a bit of manual work for me but in exchange for shaving 18 seconds out of a build that used to take around 25 seconds, I can accept the trade off.

As I mentioned [last week](/weeknotes/week-37-2026/#games), I've been inspired to add a video game photography section to my website, and the work on it is _almost_ done. I'll hopefully have it up and running soon, but I don't know if I'll have time next week given how much is going on.
