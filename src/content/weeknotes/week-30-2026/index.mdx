# Work

I have complex feelings about [Sean Goedecke](https://www.seangoedecke.com/about)'s writing, but I decided to take some of the advice from the [doing nothing at work](https://www.seangoedecke.com/doing-nothing-at-work/) essay to free up my time for interesting opportunities that might turn up. This paid off pretty quickly, and I spent this week mostly focusing on one of those projects. A bulk of the work was already in place, so I've been able to move fast on it. Hopefully it'll be done and dusted by next week, and I can go back to focusing on new feature work for [RealtimeKit](https://developers.cloudflare.com/realtime/realtimekit/).

That said, I did cap off the RealtimeKit [monorepo](https://en.wikipedia.org/wiki/Monorepo) side quest by moving the final piece in: the iOS UI Kit. This was a bit of a hassle due to how the dependencies work out, but ultimately everything fell into place. I am fully confident this house of cards will fall apart the second I trigger the release pipeline, but that's a problem for a later date.

# Meta

The site has had a bunch of changes this week as I mucked around with adding the [/reading](/reading) page. The nav links at the top are now truncated to be 3 + overflow as I keep adding standalone pages. The resulting UI is still a little too wide for mobile, so I will probably keep iterating on this to make it look nice on all sizes.

The webmentions server that processes outgoing content now uses the hidden `p-summary` element instead of `e-content` to populate the body, so people receiving Webmentions from me will start seeing shorter "description" fields instead of the awkwardly HTML-stripped main content.

# Cooking

Not a lot of cooking this week as we first made a big portion of paneer and ate it over two days, then Yash fell sick so we were down to plain khichdi. I'm also not having the best time with food, so the kitchen was mostly unused this week. The paneer was our first foray into blending roasted veggies to make a curry and the result was exactly as smooth and creamy as promised. Will definitely be doing more of this going forward given how easy it was to put together.
