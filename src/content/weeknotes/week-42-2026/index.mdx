## Tangent about tangents

How do people cope with their work just decomposing into a series of tangents? This is a real breakdown of how I started working on a fundamental rearchitecture of the Mobile SDK's handling of reconnections (modelled after recent changes in the Web SDK) and ended up spending two days doing NONE of it.

```mermaid
flowchart TD
  Task(["I start working on porting reconnection improvements"])
  Tangent1("I realise I need LLMs to be able to reliably test the flow as changes land")
  Tangent1_5("I write a skill to teach LLMs how to reliably enter a meeting and simulate a disconnect")
  Tangent1_9("I need to build a new debug hook because my automation tools are bad at typing into phones")
  Tangent2("I push up my spec and task breakdown for review and find CI to be too slow")
  Tangent2_5("As I tweak the build tool to slim down CI jobs I notice all files are not being covered by the formatter anymore")
  Tangent2_9("I now have to go fix the formatter and propagate that update back to the project")

  Task --> Tangent1
  Tangent1 --> Tangent1_5
  Tangent1_5 --> Tangent1_9
  Task --> Tangent2
  Tangent2 --> Tangent2_5
  Tangent2_5 --> Tangent2_9
```

Genuinely starts feeling like I've actually built nothing of value when the moment I touch it everything starts crumbling to dust. Maybe I'm just being dramatic and having big feelings for no-therapy-in-a-bit reasons. Onwards!
