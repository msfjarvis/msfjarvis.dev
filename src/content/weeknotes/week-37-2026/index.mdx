## Personal projects

Inspired by the blog roll replay feature we now have on the [IWCB Mastodon Bot](https://indieweb.social/@blr) I wanted to implement something similar for Claw, given I am currently sitting on around 1700+ bookmarked posts. I chose to forego LLMs for this and spent a few nights and mornings to implement it (pull request [here](https://github.com/msfjarvis/compose-lobsters/pull/1264)). It was fun to iterate on this over a few days since the notifications were scheduled to be once-a-day. I realized that because I've written and reviewed so much LLM authored code in my work project, I've kind of started writing new code in a similar style. Initially I was a little distraught, but thinking about it, it's just an uglier version of the "functional core, imperative shell" paradigm that I already liked before LLMs became any good. Extracting a small bit of pure logic out of a class with complex dependencies and testing it in isolation was something I had been taught way before I had had the misfortune of hearing of OpenAI. Despair conquered 🙃

### 🤖 CLANK CLANK CLANK 🤖

A few weeks ago I had clanked together a [CLI tool](https://git.msfjarvis.dev/msfjarvis/actual-budget-backfiller) to reconcile my Actual Budget account and my credit card statement. I kept tacking on small improvements as I needed them but since this is fully slop coded, the cracks have started to show, and I'm now looking at 8K lines of rubbish. I _could_ rewrite this by hand, but for something I'll use once a month at most, I chose to try a different approach to clanking to see if it yields any better results. I've seen people speak highly of [Matt Pocock's skills](https://github.com/mattpocock/skills) and decided to use them to fully restart this project from scratch. In 3 sessions it has so far fully reconstructed every feature short of actually writing transactions to Actual Budget, and done so with a properly managed issue tracker. All decisions have justifications and a record on [Linear](https://linear.app), and everything is as I wanted it to be. I'll see if I want to write about this separately, but I'm pretty impressed so far. For all intents and purposes this is still slop, but it's **significantly** more readable and looks like something I could dive into myself if needed.
